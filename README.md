# 📱 SGI3D App

Application mobile Android permettant la gestion de demandes d'impression 3D.

## 🚀 Fonctionnalités

- Authentification utilisateur
- Création de demandes d'impression (fichiers STL / GCODE)
- Prévisualisation 3D des fichiers STL
- Suivi des demandes
- Notifications en temps réel
- Gestion des rôles (étudiant, opérateur, admin)

## 🛠️ Technologies utilisées

- Kotlin
- Jetpack Compose
- Retrofit (API REST)
- MVVM Architecture
- PHP (Backend)
- MySQL (Base de données)
